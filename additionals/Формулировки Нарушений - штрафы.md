# Объясни что означают формулировки "Нарушение требований к рекомендательным технологиям", "Разглашение методов ОРМ" и пр.

Вот подробное объяснение каждой формулировки:

***

## 1. «Нарушение требований к рекомендательным технологиям»

### Что это такое:

**Рекомендательные технологии** — это алгоритмы, которые собирают, анализируют и используют данные о предпочтениях пользователей для предложения им контента, товаров или услуг. Примеры: алгоритмы YouTube, TikTok, Instagram, Яндекс.Музыки, маркетплейсов (Ozon, Wildberries).

### Что конкретно нарушается:

| Требование закона | Пример нарушения |
| :-- | :-- |
| **Информировать пользователей** о применении рекомендательных технологий | На сайте нет надпись *«На информационном ресурсе применяются рекомендательные технологии»* [^2][^4] |
| **Разместить документ «Правила применения рекомендательных технологий»** | Документ не опубликован или недоступен в общедоступном режиме [^2][^4] |
| **Описать методы сбора и анализа данных** о предпочтениях пользователей | В правилах не указано, какие данные собираются (история просмотров, клики, покупки) и как используются [^4] |
| **Не предлагать информацию с нарушением законодательства РФ** | Алгоритм рекомендует контент, нарушающий закон (экстремизм, фейки, незаконные товары) [^2][^3] |
| **Не нарушать права граждан и организаций** | Рекомендации дискриминируют пользователей по признакам, запрещённым законом [^2][^4] |

### Наказание:

- **Первичное нарушение**: штраф для юрлиц до **700 тыс. руб.**[^11][^12]
- **Повторное нарушение**: штраф до **1,4 млн руб.**[^13][^14]
- **Невыполнение требования РКН о прекращении использования технологий**: штраф до **2,8 млн руб.**[^14]

***

## 2. «Разглашение методов ОРМ»

### Что это такое:

**ОРМ** — **оперативно-розыскные мероприятия**. Это действия оперативных подразделений МВД, ФСБ, ФСИН для сбора информации о преступлении, выявления подозреваемых, сбора доказательств.

### Виды ОРМ:

| Тип ОРМ | Пример |
| :-- | :-- |
| **Следование** | Наблюдение за подозреваемым в реальном времени |
| **Запрос информации** | Получение данных от банков, провайдеров, почтовых сервисов |
| **Специальные технические средства** | Скрытая видео- и аудиозапись, датчики, жучки |
| **Опрос** | Беседы с свидетелями, потенциальными потерпевшими |
| **Просмотр документов** | Изучение документов без официального изъятия |
| **Наведение** | Внедрение оперативника в среду подозреваемых под легендой |

### Что значит «разглашение методов ОРМ»:

- **Публикация в интернете** описания того, как ФСБ/МВД проводит ОРМ: какие техники слежения используют, какие базы данных запрашивают, какие методы внедрения применяют
- **Передача информации прессе** или блогерам о спецоперациях, методах работы оперативников
- **Обучение преступников** методам противодействия ОРМ (например, через YouTube-каналы)


### Пример нарушения:

Блогер опубликовал статью: *«Как ФСБ находит наркоторговцев через Telegram: доступ к базе данных, скрытая камера, методы легендирования»* → **разглашение методов ОРМ**[^15]

### Наказание:

- **Для операторов связи и IT-компаний**: штраф **3–5 млн руб.** (первичное) → **1–3% годовой выручки, не менее 10 млн руб.** (повторное)[^11][^15]

***

## 3. «Неисполнение обязанности по авторизации пользователей» (ст. 13.55 КоАП)

### Что нарушается:

| Требование | Пример нарушения |
| :-- | :-- |
| **Использовать только российские сервисы авторизации**: номер телефона российского оператора, Госуслуги (ЕСИА), ЕБС | Сайт предлагает вход через **Gmail, Google OAuth, Apple ID, Microsoft** [^16][^17] |
| **Не разрешать иностранную электронную почту** как идентификатор | Регистрация через **gmail.com, hotmail.com, yahoo.com** [^16][^14] |
| **Не предоставлять возможность входа через иностранные сервисы** | Кнопки «Войти через Google», «Войти через Apple» на сайте [^18] |

### Наказание:

- **Граждане**: 10–20 тыс. руб. → до 40 тыс. руб.
- **Должностные лица**: 30–50 тыс. руб. → до 100 тыс. руб.
- **Юрлица**: 500–700 тыс. руб. → до 1,4 млн руб.[^16][^17]
