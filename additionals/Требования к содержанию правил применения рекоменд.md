# Требования к содержанию правил применения рекомендательных систем

На основе закона **№ 149-ФЗ «Об информации»** (ст. 10.2-2) и приказа Роскомнадзора № 149 от 06.10.2023, требования к содержанию **правил применения рекомендательных технологий** следующие:

***

## Обязательное содержание документа «Правила применения рекомендательных технологий»

### 1. Описание процессов и методов сбора данных

| Что должно быть указано | Пример формулировки |
| :-- | :-- |
| **Процессы сбора сведений** о предпочтениях пользователей | *«Сбор сведений осуществляется через: отслеживание истории просмотров, запись кликов, фиксацию времени на странице, анализ поисковых запросов»* [^2][^3] |
| **Методы систематизации данных** | *«Систематизация данных производится в базе пользовательских профилей с привязкой к идентификатору пользователя»* [^2] |
| **Методы анализа предпочтений** | *«Анализ предпочтений осуществляется с использованием алгоритмов машинного обучения на основе истории взаимодействий»* [^2][^3] |
| **Способы осуществления процессов** | *«Процесс сбора данных автоматизирован через JavaScript-скрипты, встроенные в страницы сайта»* [^2] |


***

### 2. Виды сведений о предпочтениях пользователей

| Вид сведений | Пример |
| :-- | :-- |
| **История просмотров** | Какие товары/контент пользователь смотрил [^3] |
| **Реакции на элементы** | Клики, лайки, оценки, добавление в избранное [^1] |
| **Время взаимодействия** | Сколько времени пользователь находился на странице [^3] |
| **Поисковые запросы** | Что пользователь искал на сайте [^3] |
| **Данные о карьерном пути** (для сервисов с профилем) | Опыт работы, образование, навыки [^1] |
| **Демографические данные** | Возраст, город, язык (если собираются) [^3] |


***

### 3. Источники получения сведений

| Источник | Пример формулировки |
| :-- | :-- |
| **Сайт/приложение** | *«Сведения собираются непосредственно на нашем сайте через аналитические инструменты»* [^3] |
| **Внешние платформы** | *«Данные о предпочтениях могут поступать из социальных сетей (при интеграции с Facebook/Google)»* [^2] |
| **Третьи стороны** | *«Информация о покупках может поступать от партнёров-маркетплейсов»* [^2] |
| **Cookie-файлы** | *«Сбор данных осуществляется через cookie-файлы, сохраняющие идентификатор пользователя»* [^3] |
| **Серверные метрики** | *«Анализ выполняется через серверные логи, фиксирующие IP-адрес, время запроса, тип устройства»* [^3] |


***

### 4. Описание методов предоставления информации

| Что описывается | Пример |
| :-- | :-- |
| **Как формируются рекомендации** | *«На основе собранных данных алгоритм ранжирует контент по степени релевантности предпочтениям пользователя»* [^3] |
| **Критерии ранжирования** | *«В рейтинге учитываются: история просмотров, частота взаимодействий, популярность контента среди других пользователей»* [^3] |
| **Алгоритмы и модели** | *«Используются алгоритмы коллаборативной фильтрации и content-based рекомендации»* [^3] |


***

### 5. Контактные данные владельца

| Что должно быть указано | Пример |
| :-- | :-- |
| **Наименование юридического лица** (для компаний) | *«ООО «ТехноСервис»»* [^2] |
| **ФИО владельца** (для физических лиц) | *«Иванов Иван Иванович»* [^2] |
| **Адрес электронной почты** для юридически значимых сообщений | *«recs@company.ru»* [^2][^6] |


***

### 6. Дополнительные обязательные положения

| Положение | Пример формулировки |
| :-- | :-- |
| **Отказ от нарушения прав** | *«Владелец не допускает применение рекомендательных технологий, нарушающих права и законные интересы граждан и организаций»* [^2][^3] |
| **Отказ от незаконного контента** | *«Не допускается применение рекомендательных технологий в целях предоставления информации с нарушением законодательства РФ»* [^2][^3] |
| **Согласие с политикой ПДн** | *«Обработка персональных данных для целей рекомендательных технологий осуществляется в соответствии с Политикой конфиденциальности»* [^3] |
| **Опция отказа от рекомендаций** (при технической возможности) | *«При наличии технической возможности пользователю предоставляется опция отказа от персонализированных рекомендаций»* [^3] |


***

## Требования к размещению документа:

| Требование | Описание |
| :-- | :-- |
| **На русском языке** | Текст правил должен быть на русском [^2][^6] |
| **Беспрепятственный доступ** | Без дополнительной регистрации или оплаты [^2][^6] |
| **Безвозмездно** | Доступ к документу должен быть бесплатным [^2] |
| **На видном месте** | Без наложения на другую информацию, доступно без авторизации [^2][^6] |
| **Ссылка из дисклеймера** | На сайте должна быть надпись *«На информационном ресурсе применяются рекомендательные технологии»* со ссылкой на страницу правил [^2] |


***

## Пример структуры документа:

```
ПРАВИЛА ПРИМЕНЕНИЯ РЕКОМЕНДАТЕЛЬНЫХ ТЕХНОЛОГИЙ

1. Общие положения
   - Термины и определения
   - Цель применения рекомендательных технологий

2. Процессы и методы работы рекомендательных технологий
   - Сбор сведений о предпочтениях
   - Систатизация данных
   - Анализ предпочтений
   - Способы осуществления процессов

3. Виды сведений, используемые для рекомендаций
   - История просмотров
   - Реакции на элементы
   - Время взаимодействия
   - Поисковые запросы

4. Источники получения сведений
   - Сайт/приложение
   - Cookie-файлы
   - Внешние платформы

5. Методы предоставления информации
   - Формирование рекомендаций
   - Критерии ранжирования

6. Контактные данные владельца
   - Название юрлица
   - Электронная почта

7. Дополнительные положения
   - Отказ от нарушения прав
   - Отказ от незаконного контента
   - Опция отказа от рекомендаций
```

Документ должен быть опубликован на сайте в общедоступном режиме.[^2][^6]
