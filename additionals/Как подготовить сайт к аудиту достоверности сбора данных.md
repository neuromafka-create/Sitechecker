# Как подготовить сайт к аудиту достоверности сбора данных

Для подготовки сайта к аудиту достоверности сбора данных РКН выполняются следующие шаги:

### 1. Обязательные элементы на сайте (до 30 мая 2025 г.)

| Элемент | Что требует РКН |
| :-- | :-- |
| **Баннер о сборе cookies** | Баннер с уведомлением о использовании cookie-файлов и кнопкой согласия [^4] |
| **Политика обработки ПД** | Документ с описанием всех процессов сбора и обработки персональных данных [^4] |
| **Согласие на обработку ПД** | Чекбокс с ссылкой на политику в формах сбора данных [^4] |
| **Упоминание метрических программ** | Явное указание всех сервисов аналитики (Яндекс.Метрика, Google Analytics) [^4] |
| **Согласие на рассылку** | Отдельный чекбокс для email-рассылок (если есть) [^4] |

### 2. Проверка и исправление

| Что проверять | Как исправить |
| :-- | :-- |
| **Размещение сайта и сервера в РФ** | Гарантия, что сервер находится в России (не в ЕС/США) [^4] |
| **Регистрация в реестре операторов ПД** | Проверить, что компания зарегистрирована в реестре Роскомнадзора [^4] |
| **Настройка форм** | Наличие чекбокса и ссылок на согласия в каждой форме [^4] |
| **Фото людей на сайте** | Получить согласие на размещение фотографий людей [^4] |
| **Трансграничная передача данных** | Уведомить РКН о использовании сервисов с передачей данных за рубеж [^4] |

### 3. Уведомление о трансграничной передаче

| Сервисы, требующие уведомления | Примеры |
| :-- | :-- |
| **Google сервисы** | Google Analytics, Google Tag Manager, Google ReCAPTCHA, Google Forms [^4] |
| **Другие иностранные сервисы** | Facebook Pixel, Instagram API, любые внешние аналитические системы [^4] |

### 4. Подготовка документов для инспектора

| Документ | Что содержать |
| :-- | :-- |
| **Доступы к аналитике** | Яндекс.Метрика, Яндекс.Вебмастер, Google Analytics, Google Webmasters [^5] |
| **Серверные лог-файлы** | Файлы с записями всех HTTP-запросов к серверу [^5] |
| **Техническая документация** | Схемы передачи данных, архитектура баз данных, настройки CRM [^10] |
| **Предыдущие отчеты** | Отчеты по предыдущим аудитам и проверкам [^5] |
| **Семантическое ядро** | Список всех ключевых слов и метрик сайта [^5] |

### 5. Инвентаризация данных (Data Mapping)

| Что делать | Что проверять |
| :-- | :-- |
| **Категории данных** | Какие данные собираются (email, телефон, имя, IP-адрес) [^6] |
| **Правовые основания** | Согласие, договор, законное основание обработки [^6] |
| **Контрагенты** | Кому передаются данные (партнеры, сервисы, третьи стороны) [^6] |
| **Трансграничная передача** | Есть ли передача данных за пределы РФ [^6] |
| **Сроки хранения** | Как долго хранятся данные и когда удаляются [^6] |

### 6. Чек-лист проверки

| Шаг | Проверка |
| :-- | :-- |
| 1 | Есть ли баннер cookies на сайте? |
| 2 | Опубликована ли Политика конфиденциальности? |
| 3 | Есть ли чекбокс согласия в формах? |
| 4 | Указаны все метрические сервисы? |
| 5 | Сервер находится в РФ? |
| 6 | Компания в реестре операторов ПД? |
| 7 | Уведомлено РКН о трансграничной передаче? |
| 8 | Есть фотографии людей с согласием? |

При подготовке предоставить доступы к аналитике и серверным логам для проверки инспектором.[^5]
