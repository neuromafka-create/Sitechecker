# Какая ответственность предусмотрена за использование API иностранных соцсетей

На текущий момент в законодательстве РФ **не прописана отдельная ответственность именно за использование API иностранных соцсетей**. Однако могут применяться смежные статьи КоАП, в зависимости от контекста использования:

### Возможные статьи ответственности

| Статья КоАП | Что регулирует | Штраф (должностные лица) | Штраф (юрлица) | Применимость к API соцсетей |
| :-- | :-- | :-- | :-- | :-- |
| **13.11.2** | Незаконное использование иностранных информационных систем и ПО (мессенджеры) | 30 000 – 100 000 руб. | 100 000 – 700 000 руб. | ⚠️ **Может применяться**, если API используется для коммуникации с клиентами через иностранные платформы (WhatsApp, Telegram, Facebook) [^1][^4][^6] |
| **13.31** | Нарушение порядка распространения информации и использования информационных систем | 10 000 – 30 000 руб. | 100 000 – 300 000 руб. | ⚠️ **Может применяться**, если API используется для публикации контента без соблюдения требований РКН [^5] |
| **13.11** | Незаконная обработка персональных данных | 10 000 – 30 000 руб. | 60 000 – 150 000 руб. | ✅ **Применяется**, если через API соцсетей передаются/хранятся ПДн граждан РФ без согласия [^7] |
| **13.14** | Нарушение обязанности хранить данные в РФ (локализация) | 100 000 – 200 000 руб. | 300 000 – 700 000 руб. | ✅ **Применяется**, если данные через API соцсети хранятся вне России [^7] |


***

### Ключевые нюансы:

1. **В законе № 41-ФЗ (от 1 апреля 2025) не предусмотрели конкретные санкции для API** — только для использования иностранных мессенджеров в деловом общении[^3]
2. **Ответственность будет нести компания, попадающая в список по № 41-ФЗ** (банки, маркетплейсы, крупные ресурсы), а не её подрядчик или клиент[^1]
3. **Помимо штрафов возможны дополнительные санкции**:
    - Блокировка аккаунтов в иностранных соцсетях
    - Блокировка чат-ботов, интегрированных через API[^4][^8]
4. **Повторные нарушения** могут привести к увеличению штрафов до **1–6 млн руб.** для юрлиц[^7]

***

### Вывод:

На момент июня 2026 года **отдельной статьи за использование API иностранных соцсетей нет**, но при нарушении требований по:

- коммуникации с клиентами → **ст. 13.11.2**
- обработке ПДн → **ст. 13.11**
- локализации данных → **ст. 13.14**

могут быть применены штрафы **до 700 000 руб.** для должностных лиц и **до 700 000–6 000 000 руб.** для юридических лиц.
