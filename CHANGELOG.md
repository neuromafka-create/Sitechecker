# Changelog

## [1.0.6] — 2026-08-13

### Fixed
- Просмотр скриншота Playwright больше не заменяет экран проверки: оверлей с кнопкой «Назад к проверке», Esc и клик по фону.

## [1.0.5] — 2026-08-13

### Fixed
- В десктопе кнопки скачивания отчётов и AI-документов (.xlsx / .csv / .docx) снова работают: диалог «Сохранить как…», затем Проводник с файлом.
- Включены загрузки WebView2 (`ALLOW_DOWNLOADS`); bridge `download_file` для локальных URL приложения.

## [1.0.4] — 2026-08-13

### Fixed
- Выход из админки на экран проверки остаётся в окне приложения (без перехода во внешний браузер на `http://127.0.0.1…`).
- Ссылка «← К проверке» и логотип в админ-панели без `target="_blank"`.

## [1.0.3] — 2026-08-13

### Added
- Первый запуск десктопа: установка пароля администратора в UI (хеш в `admin_settings.json` в AppData).

### Fixed
- Пароль админки больше не зависит только от устаревшего `ADMIN_PASSWORD` в конфиге.

## [1.0.2] — 2026-08-13

### Fixed
- Установка Chromium Playwright: через `node cli.js`, а не через повторный запуск `Sitechecker.exe` (второй экземпляр / зависание проверки).
- Логи без «краша» на Unicode; jobs всегда помечаются done в `finally`.

## [1.0.1] — 2026-08-13

### Fixed
- Запуск окна WebView2 после установки: user data в `%APPDATA%\Sitechecker\webview2`, GUI `edgechromium`.
- Fallback в системный браузер, если нативное окно недоступно.

## [1.0.0] — 2026-08-11

### Added
- Windows desktop shell (pywebview), PyInstaller onedir, Inno Setup `Sitechecker-Setup-1.0.0.exe`.
- Данные в `%APPDATA%\Sitechecker`.
