## Sitechecker v1.0.0 — Windows Desktop

Первый десктоп-релиз: нативное окно (WebView2), без ручного запуска браузера.

### Установка
1. Скачайте **Sitechecker-Setup-1.0.0.exe**
2. Установите (права администратора не обязательны)
3. Запустите **Sitechecker** из меню «Пуск»

### Важно
- **Данные** (история, отчёты, настройки): `%APPDATA%\Sitechecker\`
- **Chromium для Playwright** скачивается **автоматически при первом** запуске «углублённой проверки» 152-ФЗ (нужен интернет)
- API-ключ для AI-рекомендаций: админка или `.env` в data dir

### Модули
- 152-ФЗ (политика ПД, cookie, формы, согласие, трекеры)
- Санкционные ресурсы
- Авторизация / OAuth
- История аудитов
